Firebase beállítás szükséges

A konyhai kijelző valós idejű rendeléskezeléshez Firebase adatbázist használ.
Ez teljesen ingyenes — az alábbi lépések ~5 percet vesznek igénybe.

1
Látogasd meg:
console.firebase.google.com → „Projekt hozzáadása" → adj nevet (pl. aramis-rendeles)
2
Bal menü → Build → Realtime Database → Adatbázis létrehozása
Helyszín: europe-west1 (Belgium) — tesztelési módban indítsd
3
Szabályok fülön cseréld le a tartalmat erre, majd kattints „Közzétesz"-re:
{ "rules": { ".read": true, ".write": true } }
4
Projekt beállítások ⚙ → Webalkalmazás hozzáadása (</>)
Adj nevet, regisztrálj — megjelenik a firebaseConfig objektum
5
Nyisd meg a firebase-config.js fájlt és töltsd ki az értékeket
az imént kapott config alapján, majd mentsd el — ennyi!
